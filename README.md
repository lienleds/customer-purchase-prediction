# customer-purchase-prediction

Logistic Regression model for customer purchase prediction - AI Foundation training exercise.

## Files

- `customer_purchase_prediction.py` - trains and evaluates the Logistic Regression model.
- `create_presentation.py` - generates the PowerPoint presentation from source.
- `customer_purchase_prediction.pptx` - generated training presentation.
- `requirements.txt` - Python dependencies for the scripts.

## Generate the presentation

```bash
python -m pip install -r requirements.txt
python create_presentation.py
```

The command creates `customer_purchase_prediction.pptx` in the repository root.

## Open the presentation

- Windows: double-click `customer_purchase_prediction.pptx`
- macOS: `open customer_purchase_prediction.pptx`
- Linux: `xdg-open customer_purchase_prediction.pptx`

## Run the training script

```bash
python customer_purchase_prediction.py
```

Use the script output to replace any presentation placeholders for exact accuracy or runtime measurements.
